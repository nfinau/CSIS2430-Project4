# Project 4 Documentation

This folder contains all supporting documentation for the Monopoly simulation project.

## Contents

- **project_plan.md** – Outlines roles, milestones, and development timeline  
- **proj_4_scope.md** – Defines what is included and excluded in the simulation  
- **pseudocode.md** – Describes the overall logic and structure of the program  
- **test-plan.md** – Details testing approach, features to verify, and edge cases  
- **test_results.md** – Includes testing outcomes, sample output, and verification evidence  

## Notes

This project was completed independently. All documentation, implementation, and verification work were handled by a single contributor.
